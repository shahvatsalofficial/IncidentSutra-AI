# Contributing

Created by Vatsal Shah. Open a focused issue with reproducer, actual input format and expected output (using **synthetic** data). Write tests before changing core logic. Run `npm test` on Node 20+ and test on Windows/macOS/Linux if possible. Preserve read-only defaults, evidence links, redaction, missing-data disclosures and the no-key core. Do not bundle new optional dependencies without license and security review. Contributors retain attribution under the Apache-2.0 terms.
