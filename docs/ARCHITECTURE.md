# Architecture
Enterprise: teams, incident ownership, human approval and private data boundaries. System: offline CLI ingestion, normalized evidence graph, correlation engine, hypothesis register, immutable-ish local report bundle and optional read server. Components: ingest, analyzer, reporter, validator, installer, HTTP server. Data: stable IDs, timezone-normalized timestamp, SHA-256 source hash, source record, redacted content, supporting and contradicting IDs. Runtime: Node >=20, no mandatory dependencies. A future production service needs distinct auth, RBAC, storage, retention and network threat model.
