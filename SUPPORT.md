# Support

- **Bugs and questions:** open an issue at https://github.com/shahvatsalofficial/IncidentSutra-AI/issues. Include the command, Node version, OS and a **sanitized** reproduction.
- **Security:** do not open a public issue. Use GitHub private vulnerability reporting (see `SECURITY.md`).
- **Never post** real logs, tokens, customer data or production hostnames.
- This is a volunteer-maintained open-source project with no service-level agreement. It is advisory tooling and is not a substitute for your incident commander, vendor tooling or professional judgement.
